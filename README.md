# FeedMyBrain 🧠

Eine Lern-WebApp für Schüler, um sich gezielt auf Tests und Prüfungen in der Schule vorzubereiten.

## Ziel

FeedMyBrain soll das Lernen für Klassenarbeiten und Prüfungen strukturierter, motivierender und effizienter machen.

## MVP

Der erste Meilenstein ist eine **Prüfungsvorbereitung** für eine konkrete anstehende Prüfung. Umfang und Funktionen werden im Requirement Engineering festgelegt.
